# Editor de Código Integrado - OptiCode QA

## Descripción
Se ha implementado un editor de código integrado en la interfaz web de OptiCode QA que permite a los usuarios escribir, validar y guardar código Python directamente desde el navegador, sin necesidad de crear archivos manualmente.

## Características Principales

### 1. Interfaz Modal Intuitiva
* Modal elegante y moderno que se abre con un clic.
* Diseño consistente con el tema visual de OptiCode QA.
* Responsive y adaptable a diferentes tamaños de pantalla.

### 2. Editor de Código Completo
* **Campo de nombre:** Permite especificar el nombre del archivo Python.
* **Área de texto amplia:** Espacio generoso para escribir código que incluye:
  * Fuente monoespaciada (JetBrains Mono).
  * Resaltado visual.
  * Tamaño ajustable verticalmente.
  * Placeholder con ejemplo de código.

### 3. Validación de Sintaxis
* Botón **"Validar Sintaxis"** que verifica el código antes de guardar.
* Detecta errores de sintaxis Python.
* Muestra mensajes claros indicando:
  * Sintaxis válida.
  * Errores con número de línea y descripción.

### 4. Guardado Inteligente
* Botón **"Guardar y Usar"** que realiza las siguientes acciones:
  * Guarda el código en la carpeta `src/`.
  * Agrega automáticamente la extensión `.py` si hace falta.
  * Actualiza la lista de códigos disponibles.
  * Selecciona automáticamente el nuevo archivo.
  * Cierra el modal tras un guardado exitoso.

## Cómo Usar

### Paso 1: Abrir el Editor
1. Inicia el servidor ejecutando: `python src/servidor_paso1_web.py`
2. Abre tu navegador en `http://localhost:5000`
3. Localiza la sección **"Código a Analizar"**.
4. Haz clic en el botón **"Editor de Código"**.

### Paso 2: Escribir Código
1. En el campo **"Nombre del archivo"**, ingresa un nombre descriptivo (por ejemplo: `mi_algoritmo.py`).
2. En el área de texto, escribe tu código Python.

### Paso 3: Validar (Opcional)
1. Haz clic en **"Validar Sintaxis"**.
2. Revisa el mensaje de estado.
3. Corrige los errores en caso de ser necesario.

### Paso 4: Guardar y Usar
1. Haz clic en **"Guardar y Usar"**.
2. El sistema guardará el archivo y lo seleccionará automáticamente.
3. Ejecuta la auditoría presionando el botón **"EJECUTAR"**.

## Implementación Técnica

### Backend (Flask)

* **Endpoint:** `/api/guardar-codigo`
  * **Recibe:** `{ "codigo": "...", "nombre": "archivo.py" }`
  * **Guarda en:** `src/nombre.py`
  * **Retorna:** `{ "success": true, "nombre": "...", "lineas": N }`

* **Endpoint:** `/api/validar-codigo`
  * **Recibe:** `{ "codigo": "..." }`
  * **Usa:** `compile(codigo, '<string>', 'exec')`
  * **Retorna:** `{ "valido": true/false, "mensaje": "..." }`

### Frontend (JavaScript)
Funciones Principales:
* `toggleEditorCodigo()` - Abre o cierra el modal.
* `validarCodigoEditor()` - Valida la sintaxis del código.
* `guardarCodigoEditor()` - Guarda y selecciona el código.

## Consideraciones

### Seguridad
> **Nota de seguridad:**
> * El código se ejecuta directamente en el servidor.
> * Se recomienda usar este entorno únicamente en contextos de desarrollo o educativos.
> * No exponer la aplicación a internet sin las medidas de seguridad y aislamiento (sandboxing) adecuadas.

### Limitaciones
* Solo valida la sintaxis, no previene errores en tiempo de ejecución (runtime).
* No cuenta con autocompletado de código.
* No incluye resaltado de sintaxis en tiempo real dentro del área de texto.
